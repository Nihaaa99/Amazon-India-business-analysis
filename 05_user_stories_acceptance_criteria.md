# Amazon India — User Stories and Acceptance Criteria

**Version:** 1.0  
**Prepared by:** Independent Business Analyst

## Introduction
These user stories describe the main customer activities identified during the exploration. Acceptance criteria explain what should happen for each story to be considered satisfied.

## US-01: Browse products
As a customer, I want to browse product categories so that I can discover products that interest me.
- Product categories are visible.
- Customers can select a category.
- Relevant products are displayed.

## US-02: Search and filter products
As a customer, I want to search, filter and sort products so that I can find products matching my requirements.
- Customers can enter a product name.
- Available filters include price, reviews, discounts and availability.
- Customers can sort results.
- Results reflect selected filters and sorting.

## US-03: View product information
As a customer, I want to view product information so that I can make an informed purchase decision.
- Product name, images and specifications are displayed.
- Price and offers are visible.
- Ratings and reviews are accessible.
- Available variants are displayed.

## US-04: Review customer feedback
As a customer, I want to read ratings and reviews so that I can understand other customers' experiences.
- Overall ratings are displayed.
- Written reviews are accessible.
- Customer-uploaded images are displayed when available.
- Helpful votes are visible when available.

## US-05: Manage shopping cart
As a customer, I want to add, remove and update products in my cart so that I can manage intended purchases.
- Customers can add a product.
- Customers can increase or decrease quantity.
- Customers can remove a product.
- Cart subtotal updates.

## US-06: Select delivery address
As a customer, I want to select or update my delivery address so that my order can be delivered to the correct location.
- Saved addresses are displayed.
- Customers can select an address.
- Customers can add or update an address.
- Delivery information reflects the selected location.

## US-07: Compare delivery options
As a customer, I want to view delivery options and charges so that I can choose a suitable delivery method.
- Available options are displayed.
- Estimated dates are visible.
- Delivery and handling charges are shown.
- Available offers or free-delivery benefits are displayed.

## US-08: Review order summary
As a customer, I want to review the order amount before payment so that I know how much I need to pay.
- Original prices are displayed.
- Discounts and savings are shown.
- Additional charges are included.
- Final payable amount is visible.

## US-09: Select payment method
As a customer, I want to choose an available payment method so that I can complete my purchase conveniently.
- Available methods are displayed.
- Customers can select an eligible option.
- Selected option is identifiable before proceeding.

## US-10: Receive order confirmation
As a customer, I want confirmation after placing an order so that I know my purchase has been recorded.
- Confirmation appears after successful order placement.
- Order details are accessible.
- Tracking information is available when generated.

## US-11: Track orders
As a customer, I want to track my shipment so that I can understand delivery progress.
- Shipment progress is displayed.
- Available delivery stages are visible.
- Estimated delivery date is accessible.
- Order details are available.

## US-12: Request returns or replacements
As a customer, I want to request a return or replacement for an eligible product so that I can resolve a purchase-related issue.
- Return eligibility is displayed.
- Available return or replacement options are shown.
- Customers can select an applicable reason.
- Pickup and refund information is explained where available.

## US-13: Contact customer support
As a customer, I want to contact support when I face an order-related problem so that I can receive assistance.
- Relevant help options are available.
- Customers can access support for order-related issues.
- More complex issues have an escalation route where supported.

## Conclusion
These stories cover the main customer activities observed during the website exploration. They will be used for the traceability matrix and test cases.
